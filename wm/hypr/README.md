# hyprland settings

## Required packages

Here is a list of packages this hyprland config requires.
Notice that the list might not contain some packages but it is required.

- fcitx5
- fcitx5-hangul
- ghostty
- grim (screen capturing)
- hypridle
- hyprlock
- icedrive
- nwg-displays
- pamixer
- playerctl
- thunar
- vivaldi
- walker
- wallust
- waybar
