To use this theme, you must type
sudo pacman -S qt5 sddm qt6-svg qt6-virtualkeyboard qt6-multimedia-ffmpeg 

Then copy `almagest-sddm` directory into `/usr/share/sddm/themes`.

Then change the config file in `/etc/sddm.conf` as follows:
```conf
[Theme]
Current=almagest-sddm
```
