** Font
Doom exposes five (optional) variables for controlling fonts in Doom:
- *doom-font*: the primary font to use
- *doom-variable-pitch-font*: a non-monospace font
- *doom-big-font*: used for `doom-big-font-mode'; use this for presentations or streaming.
- *doom-unicode-font*: for unicode glyphs
- *doom-serif-font*: for the `fixed-pitch-serif' face
Using the command =C-h v doom-font=, more information about doom-fonts can be shown.

Fonts that I am using describes in the following table:
| Font Controller          | Font Name               |
|--------------------------+-------------------------|
| doom-font                | Comic Code Ligatures    |
| doom-variable-pitch-font | FiraCode Nerd Font Mono |
| doom-big-font            | -                       |
| doom-unicode-font        | D2Coding ligature       |
| doom-serif-font          | -                       |

#+BEGIN_SRC elisp
(setq doom-font (font-spec :family "Comic Code Ligatures" :size 12)
      doom-variable-pitch-font (font-spec :family "FiraCode Nerd Font Mono" :size 12)
      doom-unicode-font (font-spec :family "D2Coding ligature" :size 12))
#+END_SRC

** Auto Activating Snippets
#+BEGIN_SRC elisp
(use-package aas
  :ensure t
  :hook (latex-mode .	aas-activate-for-major-mode)
  :hook (tex-mode	.	aas-activate-for-major-mode)
  :config
  (aas-set-snippets 'tex-mode
	"MK"  (lambda () (interactive)
		    (yas-expand-snippet "\\$$1\\$$0"))
	:cond #'texmathp ; expand only while in math
    ;; bind to functions!
    "//" (lambda () (interactive)
           (yas-expand-snippet "{$1 \\over $2}$0")))
  (aas-set-snippets 'latex-mode
	"MK"  (lambda () (interactive)
		    (yas-expand-snippet "\\$$1\\$$0"))
	:cond #'texmathp ; expand only while in math
    ;; bind to functions!
    "//" (lambda () (interactive)
           (yas-expand-snippet "\\frac{$1}{$2}$0")))
  ;; disable snippets by redefining them with a nil expansion
  (aas-set-snippets 'latex-mode
    "supp" nil))
#+END_SRC

** Formatting
=C-c C-f= is used for formatting the current buffer.
#+BEGIN_SRC elisp
(defun format-all-buffer-and-save ()
    "Format a buffer and save it"
  (interactive)
  (if (derived-mode-p 'zig-mode)
      (zig-format-buffer)
      (progn (format-all-buffer)
            (save-buffer))))

(map! :desc "Formatting Buffer" :ni "C-c C-f" #'format-all-buffer-and-save)
#+END_SRC
